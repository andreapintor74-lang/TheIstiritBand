Metti qui le foto della gallery del sito (sezione "Gallery"), con questi nomi:

- live-01.jpg  -> foto principale/verticale (card "tall")
- live-02.jpg  -> foto standard
- live-03.jpg  -> foto standard
- live-04.jpg  -> foto orizzontale/larga (card "wide")

Puoi aggiungere altre foto: apri index.html, cerca la sezione <section id="gallery">
e duplica un blocco <figure class="photo-card">...</figure> aggiungendo il nuovo file
con percorso "assets/gallery/nomefile.jpg".

Consiglio: usa immagini già ottimizzate per il web (JPG, max ~300-500 KB l'una)
per mantenere il sito veloce da caricare.
